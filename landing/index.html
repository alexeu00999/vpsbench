Всё, что нужно для оценки сервера

Инструмент собирает наиболее важные метрики, позволяя за пару минут понять реальную производительность купленного VPS.

CPU Бенчмарк

Вычисляет количество операций в секунду. Проверяет производительность как на одном ядре (Single-core), так и во многопоточном режиме (Multi-core).

Диски и I/O

Измеряет последовательное чтение и запись (МБ/с), а также случайные операции блоками 4K (IOPS). Отдельно тестирует каждый подключенный диск.

Глобальная сеть

Проверяет скорость скачивания и отдачи до серверов на разных континентах (Европа, США, Азия), а также базовый пинг до DNS.

Интерактивный TUI

Выбирайте компоненты для теста с помощью чекбоксов в красивом консольном меню. Встроен таймер автостарта на 3 секунды.

Система рейтинга

Сравнивает ваш сервер с "эталонным" мощным дедиком и выводит понятную оценку в процентах (0-100%) с цветовой индикацией.

JSON Вывод

Запускайте с флагом --json для интеграции результатов в ваши пайплайны, системы мониторинга или CI/CD без лишнего визуального шума.

Гибкие варианты запуска

Запуск через Docker

Идеально, если не хотите ничего устанавливать в систему.

docker run --rm -it vpsbench/vpsbench

Автоматический режим

Пропускает интерактивное меню и запускает все тесты.

vpsbench --auto

Выборочные тесты

Запускает только CPU и RAM тесты без проверки сети и диска.

vpsbench --cpu --ram
