# Быстрый старт

## Требования

- **Linux** (основная платформа) или **macOS**
- Для Docker-варианта: Docker 20.10+

## Установка

### Вариант 1: Одна команда (Рекомендуется)

```bash
curl -sL https://raw.githubusercontent.com/user/vpsbench/main/install.sh | bash
```

Скрипт автоматически:
1. Определит ОС (Linux/macOS) и архитектуру (amd64/arm64).
2. Загрузит последнюю версию бинарного файла с GitHub.
3. Установит бинарный файл в `/usr/local/bin` (потребуются права sudo).
4. Проверит успешность установки.

### Вариант 2: Docker

```bash
docker run --rm -it vpsbench/vpsbench
```

Docker-образ содержит всё необходимое. Подходит для серверов без прямого доступа.

### Вариант 3: Сборка из исходников

```bash
git clone https://github.com/user/vpsbench.git
cd vpsbench
go build -o vpsbench ./cmd/vpsbench/
./vpsbench
```

## Первый запуск

```bash
./vpsbench
```

При запуске появится интерактивное меню выбора компонентов:

```
Выберите компоненты для тестирования
Автостарт через: 3 сек...
(стрелки + Пробел для выбора, Enter для старта):

[x] Базовый тест CPU (Single/Multi)
[x] Тест оперативной памяти (RAM)
[x] Тест сети (Download/Upload/Ping)
[x] Диск: /dev/sda (System, 50GB)
[ ] Диск: /dev/sdb (Data, 500GB)
```

Если ничего не выбирать — через 3 секунды запустятся тесты по умолчанию (все отмеченные).

## Флаги запуска

```bash
# Запуск без интерактивного меню (всё по умолчанию)
./vpsbench --auto

# Только CPU тест
./vpsbench --cpu

# JSON-вывод (для автоматизации)
./vpsbench --json
```
