# VPSBENCH

> Бенчмарк VPS и серверов одной командой. Красивый вывод с цветными прогресс-барами.

Комплексный инструмент для тестирования производительности серверов: CPU, RAM, диски, сеть. Результаты выводятся в терминале с цветной псевдографикой и процентной оценкой относительно эталонной конфигурации.

## Быстрый старт

```bash
# Установка и запуск одной командой
curl -sL https://raw.githubusercontent.com/user/vpsbench/main/install.sh | bash

# Или через Docker
docker run --rm -it vpsbench/vpsbench
```

## Использование CLI

```bash
# Интерактивный запуск (по умолчанию)
vpsbench

# Пропустить выбор, запустить всё (автоматический режим)
vpsbench --auto

# Запустить только конкретные тесты
vpsbench --cpu --ram

# Вывод в формате JSON для автоматизации
vpsbench --json > report.json

# Отключить цвета (для лог-файлов)
vpsbench --no-color
```

## Ключевые возможности

- **CPU тест** — single-core и multi-core операции/сек
- **RAM тест** — скорость чтения/записи памяти
- **Disk I/O** — последовательное/случайное чтение и запись по каждому диску
- **Сеть** — пинг, скорость до серверов в EU, US, Asia
- **Интерактивный выбор** — чекбоксы компонентов с 3-секундным автостартом
- **Цветной вывод** — красный → оранжевый → белый → жёлтый → зелёный по шкале 0-100%
