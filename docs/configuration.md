# Конфигурация

## Переменные окружения

Вы можете настроить поведение VPSBENCH с помощью переменных окружения. Это полезно для интеграции в CI/CD или автоматизированные скрипты.

| Переменная | Значение по умолчанию | Описание |
|------------|-----------------------|----------|
| `LOG_LEVEL` | `info` | Уровень логирования (`debug`, `info`, `warn`, `error`) |
| `LOG_FORMAT` | `text` | Формат логов (`text`, `json`) |
| `BENCH_TIMEOUT` | `300s` | Общий таймаут выполнения всех тестов |

Пример использования:

```bash
LOG_LEVEL=debug ./vpsbench
```

## Конфигурационные файлы

На данный момент VPSBENCH не использует внешние файлы конфигурации (.yaml или .json), предпочитая флаги CLI и переменные окружения для максимальной портативности.

## Базовая конфигурация (Эталон)

Рейтинг рассчитывается относительно следующей конфигурации, которая принята за 100%:

- **CPU:** 8-core Ryzen 9 (современное поколение)
- **RAM:** 16 GB DDR5
- **Disk:** NVMe Gen4
- **Network:** 10 Gbps Port

Если ваше железо мощнее, вы можете увидеть значения > 100%.
