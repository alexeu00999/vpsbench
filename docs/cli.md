# CLI-интерфейс

## Базовое использование

```bash
# Интерактивный режим (по умолчанию)
vpsbench

# Автоматический режим (без меню, тесты по умолчанию)
vpsbench --auto

# JSON-вывод (для автоматизации)
vpsbench --json
```

## Флаги

| Флаг | Описание |
|------|----------|
| `--auto` | Пропустить интерактивное меню, запустить всё по умолчанию |
| `--cpu` | Только CPU тест |
| `--ram` | Только RAM тест |
| `--disk` | Только Disk I/O тест |
| `--network` | Только сетевой тест |
| `--json` | Вывод в формате JSON |
| `--no-color` | Без цветов |

Флаги можно комбинировать:

```bash
# CPU + RAM тест в JSON
vpsbench --cpu --ram --json
```

## Интерактивный режим

При запуске без флагов `--auto` или конкретных тестов, появляется меню выбора:

```
Выберите компоненты для тестирования
Автостарт через: 3 сек...
(стрелки + Пробел для выбора, Enter для старта):

[x] Базовый тест CPU (Single/Multi)
[x] Тест оперативной памяти (RAM)
[x] Тест сети (Download/Upload/Ping)
[x] Диск: /dev/sda (System, 50GB)
[ ] Диск: /dev/sdb (Data, 500GB)
```

- **Стрелки вверх/вниз** — навигация
- **Пробел** — включить/выключить компонент
- **Enter** — запустить выбранные тесты
- **Таймер 3 сек** — если не нажать ничего, запускаются отмеченные по умолчанию

Диски определяются автоматически. Системный диск включён по умолчанию, дополнительные — нет.

## Цветовая шкала

Прогресс-бары окрашиваются в зависимости от процента:

| Диапазон | Цвет | Оценка |
|----------|------|--------|
| 0-20% | Красный | Плохо |
| 21-40% | Оранжевый | Ниже среднего |
| 41-60% | Белый | Средне |
| 61-80% | Жёлтый | Хорошо |
| 81-100% | Зелёный | Отлично |
