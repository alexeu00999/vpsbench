# Роадмап проекта

> Комплексный VPS/серверный бенчмарк одной командой с красивым цветным выводом

## Вехи

- [x] **Настройка проекта** — архитектура, документация, Makefile, Docker
- [x] **Скелет приложения** — Go модуль, Cobra CLI, интерфейс Benchmark, оркестратор, точка входа
- [x] **Детект системы** — определение CPU, RAM, дисков, ОС, локации сервера
- [x] **CPU бенчмарк** — single-core и multi-core ops/s
- [x] **RAM бенчмарк** — скорость чтения/записи памяти
- [x] **Disk I/O бенчмарк** — sequential read/write, random 4K IOPS, автодетект дисков
- [x] **Сетевой бенчмарк** — пинг, download/upload до серверов EU, US, Asia
- [x] **Система рейтинга** — расчёт процентов относительно базовой конфигурации (Ryzen 9, NVMe Gen4, 10Gbps, 16GB DDR5)
- [x] **Интерактивный TUI** — BubbleTea чекбоксы с 3-секундным таймером автостарта, выбор дисков
- [x] **Цветной вывод результатов** — Lipgloss прогресс-бары, цветовая шкала (красный→зелёный), ASCII-рамки
- [ ] **CLI флаги и режимы** — --auto, --cpu, --ram, --disk, --network, --json, --no-color
- [ ] **Установка одной командой** — install.sh скрипт (wget/curl), Docker-образ на Docker Hub, кросс-компиляция
- [ ] **Центральный сервер (V2)** — API для сбора результатов, сравнение между серверами, ссылки на результаты
