# Проект: AIF-VPSBENCH (SUPER-BENCH)

## Обзор
Комплексный инструмент бенчмаркинга VPS и серверов. Запускает тесты производительности и выводит результаты в виде красивой цветной ASCII-графики в терминале. Установка одной командой, интерактивный CLI с автостартом, поддержка Docker для универсального развёртывания.

## Основные функции
- **CPU бенчмарк:** Измерение операций/сек в одноядерном и многоядерном режиме (Реализовано)
- **RAM бенчмарк:** Измерение скорости чтения/записи памяти (Реализовано)
- **Disk I/O бенчмарк:** Последовательное чтение/запись, случайные 4K IOPS по каждому диску (Реализовано)
- **Сеть бенчмарк:** Пинг, скорость загрузки/отдачи до нескольких континентов (В разработке)
- **Интерактивный CLI:** Выбор компонентов чекбоксами с 3-секундным таймером автостарта (В разработке)
- **Визуальный вывод:** Цветные прогресс-бары с процентной оценкой относительно базовой конфигурации (В разработке)
- **Установка одной командой:** `wget -qO- bench.sh | bash` или через Docker
- **Автодетект системы:** CPU модель, RAM, диски, сетевые интерфейсы, ОС, локация (Реализовано)

## Базовая конфигурация (100%)
- CPU: 8-ядерный Ryzen 9
- Диск: NVMe Gen4, 128gb
- Сеть: 10 Gbps
- RAM: 16 GB DDR5

## Цветовая шкала
- 0-20%: Красный (плохо)
- 21-40%: Оранжевый (ниже среднего)
- 41-60%: Белый (средне)
- 61-80%: Жёлтый (хорошо)
- 81-100%: Зелёный (отлично)

## Технологический стек
- **Язык:** Go
- **CLI фреймворк:** Cobra (структура CLI) + BubbleTea/Lipgloss (интерактивный UI, цвета)
- **Дистрибуция:** Единый бинарник, Docker-образ

## Архитектурные заметки
- Единый бинарник — никаких зависимостей в рантайме
- Модульные бенчмарк-раннеры (CPU, RAM, Disk, Network) — каждый независим
- Параллельное выполнение тестов через Goroutines
- JSON-вывод для будущей интеграции с сервером
- Graceful fallback когда конкретный тест не может запуститься

## Нефункциональные требования
- Логирование: Настраиваемое через LOG_LEVEL
- Обработка ошибок: Graceful degradation по каждому модулю бенчмарка
- Портативность: Linux основная, macOS вторичная
