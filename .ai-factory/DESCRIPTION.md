# Проект: AIF-VPSBENCH (SUPER-BENCH)

## Обзор
Комплексный инструмент бенчмаркинга VPS и серверов. Запускает тесты производительности и выводит результаты в виде красивой цветной ASCII-графики в терминале. Установка одной командой, интерактивный CLI с автостартом, поддержка Docker для универсального развёртывания.

## Основные функции
- **CPU бенчмарк:** Измерение операций/сек в одноядерном и многоядерном режиме
- **RAM бенчмарк:** Измерение скорости чтения/записи памяти
- **Disk I/O бенчмарк:** Последовательное чтение/запись, случайные 4K IOPS по каждому диску
- **Сеть бенчмарк:** Пинг, скорость загрузки/отдачи до нескольких континентов (EU, US, Asia)
- **Интерактивный CLI:** Выбор компонентов чекбоксами с 3-секундным таймером автостарта
- **Визуальный вывод:** Цветные прогресс-бары с процентной оценкой относительно базовой конфигурации
- **Установка одной командой:** `wget -qO- bench.sh | bash` или через Docker
- **Автодетект системы:** CPU модель, RAM, диски, сетевые интерфейсы, ОС, локация

## Базовая конфигурация (100%)
- CPU: 8-ядерный Ryzen 9
- Диск: NVMe Gen4, 128gb
- Сеть: 10 Gbps
- RAM: 16 GB DDR5

## Цветовая шкала
- 0-20%: Красный (плохо)
- 21-40%: Оранжевый (ниже среднего)
- 41-60%: Белый (средне)
- 61-80%: Жёлтый (хорошо)
- 81-100%: Зелёный (отлично)

## Технологический стек
- **Язык:** Go
- **CLI фреймворк:** Cobra (структура CLI) + BubbleTea/Lipgloss (интерактивный UI, цвета)
- **Дистрибуция:** Единый бинарник, Docker-образ
- **Docker:** Для универсального развёртывания (автодетект ОС, установка Docker если нет, запуск)

## Функции V2 (будущее)
- Центральный сервер для сбора результатов бенчмарков с нод
- Сравнение результатов между серверами/железом
- Сбор характеристик оборудования для сопоставления
- Ссылки на результаты (например, `https://super-bench.io/result/xyz123`)
- Ежегодное обновление базовых показателей

## Архитектурные заметки
- Единый бинарник — никаких зависимостей в рантайме
- Модульные бенчмарк-раннеры (CPU, RAM, Disk, Network) — каждый независим
- Параллельное выполнение тестов где возможно
- JSON-вывод для отправки на сервер V2
- Graceful fallback когда конкретный тест не может запуститься (например, нет сети)

## Нефункциональные требования
- Логирование: Настраиваемое через LOG_LEVEL
- Обработка ошибок: Graceful degradation по каждому модулю бенчмарка
- Безопасность: Никакого сбора данных в V1; V2 только с согласия
- Портативность: Linux основная, macOS вторичная, Windows через Docker
